Kiểm thử đăng nhập HTB

Chỉ dành cho quản trị viên: Appwrite Auth → JWT → Cloudflare Worker /me.

Trang kiểm thử không tự lưu email, mật khẩu hoặc JWT vào localStorage. Appwrite SDK có thể lưu phiên qua cookie/bộ nhớ trình duyệt. JWT không hiển thị. Nên xóa trang thử nghiệm khỏi GitHub sau khi kiểm tra xong.
